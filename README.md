# Pacers-four-factors-analysis
Indiana Pacers analytics project: game-by-game Four Factors plots showing eFG% drove 2024-25 wins (r = 0.63), four tested mock-SQL queries on NBA player/team/game tables, and a 5-slide strategy deck on strengths, weaknesses, 2026-27 outlook, trade targets, and an undervalued player. Built with Python, SQL, and pptxgenjs.
